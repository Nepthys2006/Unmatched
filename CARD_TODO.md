# Hero and card implementation checklist

One box per identity card detail, special ability and card (its ATK / DEF / BOOST values and every effect). Details are in `CARDS.md`. A hero box is ticked when it is scripted in `lib/engine/heroes/` and tested: every card by `test/cards_all_test.dart`, every identity card by `test/identity_all_test.dart`, every ability by a hero test (`test/heroes_*_test.dart`).

Generated by `python tool/make_card_compendium.py` (re-run it after scripting a hero).

**Engine progress: 70 / 70 heroes scripted.**

- [x] In a match, the Identity cards button (top left) or any player's plate opens every player's identity card, ability, live state and set rules (`test/match_hud_test.dart`).

## Card rules in the UI (every card)

- [x] Every card's printed ATK / DEF starts its value breakdown and every BOOST value is right (`test/cards_all_test.dart`, 880 cards).
- [x] Every card is really played (615 attacks, 462 defenses, 151 schemes; none skipped) and ends up in the right pile afterwards: discard, line, cauldron, hand, deck or removed.
- [ ] Combat panel shows each card's ATK or DEF, every boost added, and modifiers (`game.valueOf`).
- [x] Cards with no BOOST ("—") are never offered for boosting (only cards that can boost are offered; checked for all 880 cards).
- [ ] IMMEDIATELY effects resolve before DURING COMBAT, defender first; the step is highlighted.
- [ ] DURING COMBAT value changes ("the value is X instead", "+1 per...") show in the breakdown.
- [ ] AFTER COMBAT effects run after damage, including when the fighter was defeated where the card says so.
- [ ] "Draw N cards" effects add the cards to the hand and the hand count updates.
- [ ] "Look at / choose a card for them to discard" shows the opponent's hand to the chooser only.
- [ ] Effects on "each opponent" / "all enemies" hit every enemy in team and free-for-all modes.
- [ ] Canceled effects (all, or only DURING/AFTER) are greyed out in the combat panel.
- [ ] BOOSTED WITH effects trigger only when that card was used as a boost.
- [ ] ONGOING schemes stay on the table with their discard condition shown.
- [x] Shakespeare's line is visible (identity sheet: cards in order, syllables) and completions are announced in the log.

- [x] Squirrels sharing a space are drawn side by side and each can be tapped (2D and 3D).
